# CAL-CHECK-001 실사용 점검표

자동 테스트와 가상 화면 렌더링으로는 확인할 수 없어서, **실제 컴퓨터에서 직접 눌러 보고 확인해야 하는 항목**입니다.
각 항목을 해 보고 `[ ]`를 `[x]`로 바꾸거나, 이상하면 옆에 적어 두세요. 이상한 점이 있으면 그대로 알려 주시면 고칩니다.

> 확인 전에: 앱은 `.venv\Scripts\python.exe -m flowcalendar`로 켭니다.
> 데이터는 `%APPDATA%\FlowCalendar\flowcalendar.db`, 자동 백업은 같은 위치의 `backups` 폴더에 있습니다.

## 1. 알림 · 트레이 · 단축키

- [ ] 일정을 **지금부터 약 6분 뒤**로 만들고 알림을 "5분 전"으로 두면, 1분쯤 뒤에 Windows 알림이 뜬다
- [ ] 알림을 눌렀을 때 앱 창이 앞으로 나온다
- [ ] 창의 × 를 누르면 **트레이로 숨고**, 처음 한 번 "트레이에서 계속 실행됩니다" 안내가 뜬다
- [ ] 트레이 아이콘이 작업 표시줄 오른쪽에 보이고, 아이콘 모양이 알아볼 만하다 (밝은/어두운 작업 표시줄 모두)
- [ ] 트레이 아이콘 우클릭 메뉴(열기, 위젯 모드, 종료)가 동작한다
- [ ] 설정의 알림 끄기 → 알림이 울리지 않는다
- [ ] 전역 단축키(기본 Ctrl+Alt+Space)가 **다른 프로그램을 보고 있을 때도** 앱을 앞으로 가져온다 (AI 키가 있으면 빠른 추가 팝업)

## 2. 위젯 모드

- [ ] ☰ → "위젯 모드 켜기"를 누르면 테두리 없는 투명한 창이 된다
- [ ] 다른 창을 띄우면 위젯이 그 **뒤로** 가고, 바탕화면이 보일 때 위젯도 보인다
- [ ] **Win+D**(바탕화면 보기)를 눌러도 위젯이 계속 보인다 / 또는 가려지는지 확인 (동작을 적어 두세요)
- [ ] 위젯의 맨 윗줄을 끌면 창이 움직이고, 가장자리/모서리로 크기가 바뀐다
- [ ] 투명도 슬라이더(설정)를 움직이면 배경만 투명해진다. 카드와 글자는 그대로다
- [ ] 위젯 모드에서 **검정 테마**도 어색하지 않다
- [ ] 위젯을 끄고 일반 창으로 돌아오면 모서리가 네모로 돌아온다

## 3. 시작 · 종료 · 데이터

- [ ] 설정에서 "Windows 시작 시 자동 실행"을 켜고 **재부팅**하면 트레이로 조용히 시작한다
- [ ] 재부팅 후 알림(3번 항목 포함)이 이전과 같이 울린다
- [ ] 메모를 입력하고 **1초 안에 트레이 → 종료**해도, 다시 켰을 때 메모가 남아 있다
- [ ] 앱을 두 번 실행하면 새 창이 생기지 않고 기존 창이 앞으로 나온다
- [ ] 설정 → 백업 내보내기 → 가져오기가 동작한다 (가져오기 전에 현재 데이터를 자동 백업한다는 안내)
- [ ] 며칠 뒤 `%APPDATA%\FlowCalendar\backups`에 `auto-날짜.db`가 날짜마다 하나씩 생기고 7개를 넘지 않는다
- [ ] 완료한 할 일이 설정한 기간(기본 30일)이 지나면 사라진다 (시험하려면 설정의 기간을 7일로 두고 확인)

## 4. 일정 · 달력

- [ ] 일정 팝업에서 **종료 날짜**를 켜고 다른 주로 넘어가는 기간(예: 10/29~11/3)을 저장하면 색 막대가 주마다 이어져 보인다
- [ ] 막대를 눌러도 수정 팝업이 열린다 (끌지 않고 눌렀을 때)
- [ ] 한 칸에 일정이 많으면 "+N개"가 나오고, 누르면 그 날의 목록이 열린다
- [ ] 창 크기를 키우고 줄여도 막대가 칸을 따라간다
- [ ] 일정 칩을 **끌어서 다른 날에 놓으면** 날짜만 바뀌고 시간은 그대로다. 아래에 "되돌리기" 안내가 5초 뜬다
- [ ] 칩을 **Ctrl을 누른 채** 놓으면 복사본이 생기고 원본은 남는다
- [ ] 여러 날 막대를 끌 때 **잡은 칸을 기준으로** 옮겨진다 (3일짜리의 가운데 칸을 잡고 옮겼을 때)
- [ ] 반복 일정을 끌면 그 날짜 하나만 옮겨지고 나머지 반복은 그대로다
- [ ] 수정 팝업의 **복제** 버튼 → 같은 내용이 채워진 새 일정 팝업이 열린다
- [ ] 끌 때 놓을 날짜 칸이 밝게 표시된다

## 5. 검색

- [ ] 헤더의 돋보기 버튼 또는 Ctrl+F로 검색 팝업이 열린다
- [ ] 일정·할 일·메모에서 단어를 찾는다. 결과를 누르면 그 달로 이동해 수정 팝업이 열린다 (할 일은 그 날 목록, 메모는 글이 선택됨)
- [ ] Enter 로 첫 결과가 열린다

## 6. 테마

- [ ] 설정에서 테마 11가지를 눌러 보면 즉시 바뀌고, 저장하면 다음 실행에도 유지된다
- [ ] 저장하지 않고 닫으면 원래 테마로 돌아간다
- [ ] 검정 테마에서 팝업·메뉴·토스트·메모가 모두 읽힌다
- [ ] 그라데이션 3종이 보기 좋다

## 7. AI (실제 키가 필요한 항목)

- [ ] "내일 오후 3시 팀 미팅 1시간" → 날짜·시간이 맞게 등록된다
- [ ] "29일부터 31일까지 출장" → 여러 날 일정으로 등록된다
- [ ] 등록 직후 5초 안에 **되돌리기**가 된다
- [ ] 같은 문장을 다시 넣으면 "이미 같은 항목이 있어 등록하지 않았어요"
- [ ] 인터넷을 끄고 빠른 추가를 하면 입력이 "처리하지 못한 입력" 목록에 남는다
- [ ] 앱을 켰을 때 브리핑이 뜬다. AI가 느리면 10초 안에 코드가 계산한 요약으로 바뀌어 보인다
- [ ] (모델이 사라졌을 때) 설정의 모델 이름을 없는 이름으로 바꿔 두고 빠른 추가를 하면, 비슷한 모델로 대신 처리되고 "모델을 바꿨어요" 안내가 뜬다 — 이 항목은 일부러 잘못된 모델 이름을 넣어 봐야 확인됩니다

## 8. 화면 · 사용감

- [ ] 헤더의 `‹ 오늘 ›`, 돋보기, AI, M, ☰ 가 모두 같은 높이다
- [ ] 화살표 `‹ ›`가 가운데에 있다
- [ ] 마우스 휠을 슬라이더/콤보박스 위에서 굴려도 값이 바뀌지 않는다
- [ ] 한글 입력(IME) 중에 입력칸이 검게 칠해지는 현상이 없다
- [ ] 노트북 화면(작은 해상도)에서 창이 화면을 벗어나지 않는다
