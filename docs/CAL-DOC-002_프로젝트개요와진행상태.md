| 항목 | 내용 |
| --- | --- |
| 프로젝트 | Flow Calendar |
| 현재 버전 | **v1.0.0** |
| 최종 갱신 | 2026-10-29 |
| 위치 | 이 문서는 예전에 노션 메인 페이지에 있던 내용(버전, 기술 스택, 진행 상태, 문서 목록)을 대신한다. **노션은 더 이상 쓰지 않으며, 이 폴더의 문서가 기준이다.** |

## 1. 한 줄 소개

컴퓨터를 켜는 순간부터 함께하는 **로컬 우선(local-first) Windows 데스크톱 캘린더**. 월간 달력을 중심으로 일정 / To-Do / 메모를 한 화면에서 관리하고, 선택적으로 AI가 입력과 정리를 줄여 준다. 서버, 로그인, 계정이 없다.

## 2. 진행 상태

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| M1 | 월간 캘린더, 일정 CRUD(색상, 반복) | 완료 |
| M2 | Daily/Quick To-Do, Quick Memo, 우측 패널 | 완료 |
| M3 | 위젯 모드, 트레이, 알림, 단축키, 자동 시작, 설정, 백업 | 완료 |
| M4 | AI(빠른 추가, 메모 변환, 브리핑) | 완료 |
| M4 이후 추가 | 여러 날 일정, 끌어서 이동·복제, 검색, 테마 11종, 자동 백업, 완료한 할 일 보관, 모델 자동 대체 | 완료 |
| M5 | 설치 파일, 아이콘, 성능 측정, 문서 | 완료 (v1.0.0) |

**남은 일**
- 실사용 점검: [CAL-CHECK-001](CAL-CHECK-001_실사용점검표.md)의 항목을 실제 컴퓨터에서 확인 (알림, 위젯, 재부팅, 끌어서 옮기기, 실제 AI 등)
- 깨끗한 Windows에서 설치 시험
- 저장소를 Public으로 전환 (지금은 **Private**, 공개 전 점검표: [CAL-GUIDE-001](CAL-GUIDE-001_설치와실행방법.md) 8.3)

## 3. 기술 스택

| 영역 | 사용 |
| --- | --- |
| 언어 / UI | Python 3.13, PySide6(Qt) — Essentials만 사용 |
| 데이터 | SQLite 파일 하나 (`%APPDATA%\FlowCalendar\flowcalendar.db`), 스키마 버전 3, 변경은 마이그레이션 항목 추가 방식 |
| 키 저장 | keyring → Windows 자격 증명 관리자 |
| AI | Gemini / Claude / OpenAI 어댑터(표준 라이브러리 `urllib`, 추가 패키지 없음), 내 API 키(BYOK) |
| 배포 | PyInstaller(one-folder) + Inno Setup 6 설치 파일(GitHub Releases), 코드 서명 없음 |
| 저장소 | GitHub `yurim6263/flowcalendar` (Private → 이력서용으로 공개 예정), 라이선스 MIT, 커밋 이메일은 noreply 주소 |
| 테스트 | pytest (실제 AI·실제 키 저장소 호출 없음) |
| 서버 / 계정 | **없음** (Flutter, FastAPI, PostgreSQL, Firebase는 쓰지 않는다) |

## 4. 기능 요약 (자세한 요구사항은 [CAL-DOC-001](CAL-DOC-001_Ver1.0_정의서.md))

| 기능 | 정의서 |
| --- | --- |
| 월간 달력, 일정(색 5가지, 반복, 알림), 여러 날에 걸친 일정(종료 날짜)과 이어진 막대 | FR-CAL, FR-SCH-001~007 |
| 일정 끌어서 이동 / Ctrl 복사 / 복제 버튼, 5초 되돌리기 | FR-SCH-008, 009 |
| Daily/Quick To-Do, Quick Memo, 완료한 할 일 보관 기간 | FR-DTODO, FR-QTODO, FR-QMEMO, FR-DATA-003 |
| 검색(Ctrl+F): 일정·할 일·메모 | FR-SRCH-001 |
| 바탕화면 위젯 모드(반투명, 다른 창 뒤 고정), 트레이, Windows 알림, 전역 단축키, 시작 시 자동 실행 | FR-DESK-001~006 |
| 테마 11가지(다크 모드 = 검정 포함), 바로 적용 | FR-SET-003 |
| 자동 백업(하루 1회, 7개), 구조 변경 전 자동 복사, JSON 내보내기/가져오기 | FR-SET-004, FR-DATA-001~002 |
| AI: 빠른 추가(기본 확인 없이 등록 + 5초 되돌리기), 처리 못 한 입력 목록, 메모 선택 변환, 브리핑(10초 제한), 모델 자동 대체 | FR-AI-001~009 |

## 5. 하지 않는 것 (이후 버전 후보)

- Week / Day 뷰, 루틴, 프로젝트 관리, 통계, Daily Memo
- 협업, 외부 캘린더 연동, 모바일 / 웹, 로그인·계정
- 반복 일정의 "횟수 지정" 종료 조건
- 알림 스누즈(10분 뒤 다시), 키보드 단축키 확장(월 이동, 오늘, 새 일정)
- 설치판 자동 업데이트, 코드 서명

## 6. 개인정보와 보안 원칙

- 데이터는 이 컴퓨터의 로컬 SQLite 파일에만 있다. 서버로 보내지 않는다.
- AI는 선택 기능이다. 키는 **Windows 자격 증명 관리자에만** 저장하고 파일·DB·백업·내보내기·로그에 넣지 않는다(NFR-004).
- AI로 보내는 것은 **요청한 문장(또는 사용자가 고른 메모 줄), 대상 기간 일정·할 일의 제목과 시간, 오늘 날짜·시각**뿐이다. 메모 전체와 완료한 할 일은 보내지 않는다.
- 설치 파일에는 서명이 없어 Windows SmartScreen 경고가 뜰 수 있다(README, CAL-GUIDE-001에 안내).

## 8. 화면 시안(`ui_design`)과 달라진 점

시안 이미지(`ui_design` 폴더)는 용량 때문에 저장소(git)에 넣지 않고 이 컴퓨터에만 둔다. 구현이 시안과 달라진 곳:

- 상단: `‹ 오늘 ›` 순서, 돋보기(검색)·✨(AI)·M·☰ 버튼이 모두 같은 높이
- 일정 팝업: "종료 날짜" 줄, "복제" 버튼, "반복 종료일" 이름
- 설정: 테마 선택, 데이터 관리(자동 백업·완료 할 일 보관), AI 자동 등록, 투명도, 정보
- 메모: 비었을 때 불릿이 없다
- 로그인 / 회원가입 / 프로필 시안은 사용하지 않는다
